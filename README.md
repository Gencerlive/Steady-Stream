# Steady Stream - Road Map

### Group Members: Spencer Mann

Steady stream is a game where you play as a fish and are meant to swim up a stream that is full of dangerous objects and animals. The goal is to make it from the ocean to the lake all the way up the stream just like salmon do without dying to it's many obstacles.

### Ideas for the game

I am going to have a friend salmon that you spend the journey with while also having enemies chase the player throughout difficult parkor sections. There will also being debree and odd objects flowing and knocking the player back during some sections. 

I also through about having the wind change direction and giving the player that info through a UI element. This would also be the same with the river if I felt like changning it's flow rate throughout the game.

The game will have more cutscenes and I plan to use the thing that retro games used to do in which in between cutscene some characters get out of view so I don't have to handle complex AI movement with following the player. Also I find it that being followed by an AI gets real annoying, real fast.
